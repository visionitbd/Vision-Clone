# Vision Clone (Android App Cloner)

Clone installed Android apps directly onto your Home Screen with automatic serial numbering (**1, 2, 3...**) — no Work Profile required.

## Highlights
- **Custom Branding:** Named **Vision Clone** with custom launcher & adaptive icons.
- **No Work Profile:** Installs standalone serial clones (`App 1`, `App 2`, `App 3`) straight onto the normal Home Screen.
- **Split APK (App Bundle) Support:** Patches, ZIP-aligns, signs, and installs `base.apk` together with all split APKs using Android's `PackageInstaller`.
- **My Clones Manager:** Launch or uninstall cloned apps in one tap.

## Cloud Build via GitHub Actions
1. Upload all files inside this folder to a new GitHub repository.
2. Make sure `.github/workflows/build-apk.yml` exists in the repository.
3. Open the **Actions** tab and download **VisionClone-APK** once the build completes.
